# LandBank Acquisition KB

## Operating model
- Originate. Acquire. Develop. Monetise.
- SalesPro is source truth.
- Assets contain parcel records.
- Parcels require evidence.
- Screen before seller outreach.
- Grid first. Planning second.
- Unknown stays unknown.
- Initial land cap: £1m.
- Prioritise 100+ acre holdings.
- Keep updates brutally concise.

## Pipeline definitions
- Asset = acquisition opportunity.
- Parcel = underlying land unit.
- Raw land = purchase candidate.
- Project rights = rights acquisition.
- Consented project = advanced acquisition.
- Vendor engaged = active seller.
- DD = technical verification.
- Exclusivity = controlled transaction.
- Acquired = completed purchase.
